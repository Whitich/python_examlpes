# 🔢 En Küçük Öklid Mesafesi Hesaplayıcı

Bu Python projesi, kullanıcıdan alınan 5 adet (x, y) koordinat çifti arasındaki tüm ikili Öklid (Euclidean) mesafeleri hesaplar ve bu mesafelerden en küçüğünü bulur.

---

## 🚀 Özellikler

- Kullanıcıdan 5 nokta girişi alır.
- Tüm farklı ikili kombinasyonlar arasındaki Öklid mesafesini hesaplar.
- Tüm mesafeleri listeler.
- En küçük mesafeyi ekrana yazdırır.
